# ADR-0002 — Use Next.js for the web application

## Status

Accepted

## Context

EduGrid needs a modern React frontend with routing, build tooling, server/client rendering options, and a strong component ecosystem.

## Decision

Use Next.js with React and TypeScript for the web application.

## Alternatives considered

- Vite + React
- Angular
- Vue/Nuxt

## Consequences

- standardized React application structure;
- straightforward deployment options;
- access to the React/Next.js ecosystem;
- frontend remains separated from the primary business API.
