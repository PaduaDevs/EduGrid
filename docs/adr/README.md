# Architecture Decision Records

EduGrid uses Architecture Decision Records (ADRs) for significant technical decisions.

## Template

Each ADR should contain:

- Context
- Decision
- Alternatives considered
- Consequences
- Status

## Initial ADR set

Planned Sprint 0 ADRs:

1. Use TypeScript for Web and API
2. Use Next.js for the web application
3. Use NestJS for the backend API
4. Use PostgreSQL as the primary database
5. Use Python and OR-Tools for the scheduling solver
6. Use a monorepo
7. Keep the optimization engine separate from the business API
8. Use REST and OpenAPI for the application API
