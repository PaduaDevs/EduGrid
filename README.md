# EduGrid

EduGrid is an open-source academic timetable optimization platform focused on automated scheduling, conflict resolution, and resource allocation for educational institutions.

## Status

EduGrid is currently in **Sprint 0 — Foundation & Architecture**.

The project is establishing its technical foundation, development workflow, domain model, scheduling constraints, and the first optimization proof of concept.

## Planned architecture

- **Web:** Next.js + React + TypeScript
- **API:** NestJS + TypeScript
- **Database:** PostgreSQL
- **ORM:** Prisma
- **Solver:** Python + FastAPI + Google OR-Tools (CP-SAT)
- **Repository:** Monorepo with pnpm + Turborepo
- **CI:** GitHub Actions
